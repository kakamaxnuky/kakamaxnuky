## What I work on

- **Enterprise network migrations**: multi-site rollout to Cisco Meraki and FortiGate; SD-WAN migration from Cisco Viptela to Fortinet.
- **Network access and automation**: a Cisco ISE + wireless controller lab with a Python engine that enforces per-user data quotas, sends alerts through Microsoft 365 and shows usage on a small web monitor.
- **Linux and self-hosting**: a hardened Ubuntu server (SSH keys only, ufw, fail2ban, Caddy with automatic TLS, PM2, Docker) running a dozen production services.
- **Security by default**: an OWASP-based baseline on every app. Authorization enforced in the database (PostgreSQL row-level security and audited functions), no secrets in code, rate limits, captcha, immutable admin logs.
- **Web products**: Next.js, React, TypeScript, Supabase and PostgreSQL, with CI on GitHub Actions.
